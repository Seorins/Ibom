# 👶 ibom: 산모와 아기를 위한 맞춤형 케어 웹 서비스

산모와 아기를 위한 **맞춤형 일정 관리 및 정보 제공** 웹 애플리케이션입니다.  
예방접종, 병원 정보, 복지 혜택, 성장 정보 등 **분산된 정보를 통합**하여  
사용자 맞춤형으로 제공하는 것을 목표로 개발하였습니다.

---

## ✅ 프로젝트 개요

- **프로젝트명**: ibom
- **개발 기간**: 2024.07.30 ~ 2024.08.30
- **개발 인원**: 2명
- **주요 대상**: 임산부 및 육아 초기 보호자
- **목표**: 예방접종 및 성장 정보 기반 **맞춤형 케어 시스템 제공**

---

## ✨ 주요 기능

### 📅 1. 예방접종 캘린더
- 아이 생년월일 및 접종 이력 기반 맞춤형 예방접종 일정 자동 생성
- D-day 방식으로 남은 접종 일수 표시
- FullCalendar 활용한 달력 시각화

### 📈 2. 성장 정보 시각화
- 사용자 입력값 기반 성장 상태 시각화 (키/몸무게 등)
- 국가 데이터 기반 평균 성장 패턴 비교

### 🏥 3. 병원 정보 및 예약
- 공공데이터 API 연동하여 산부인과 병원 정보 표시
- 네이버 지도 API로 병원 위치 마커 표시
- 병원 예약 기능 및 출산 가능 여부 제공 (일부 예정)

### 💡 4. 복지 제도 정보 제공
- 산모와 아기를 위한 복지 제도 목록 및 신청 링크 제공
- 검색 및 필터링 기능 지원

### 🛍 5. 아이 제품 추천
- 아기 관련 제품 카드 및 상세정보 제공
- 유해 성분 아코디언, 사용자 리뷰 기능 포함
